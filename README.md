# дз1

## управление

W/A/S/D - движение
Пробел - прыжок
Left Shift - спринт
E - взаимодействие
1/2/3 - пасхалко

## Реализация

- C++-персонаж на основе Third Person Template.
- Спринт и взаимодействие через Enhanced Input.
- Делегат взаимодействия с выводом сообщения в Blueprint.
- Переключение анимации спринта по bIsSprinting.
- 1/2/3 нанейронено

## дз2

Content/AI/Lvl_PCGPatrol - стартовая карта
Управление то же (пасхалко всё ещё работает но не актуально т.к. камера теперь от третьего лица)

PCG_Obstacles - сетка точек. Для повторной генерации выберите PCG Volume и нажмите Generate

AHomeworkAICharacter и AHomeworkAIController - патруль и погоня

BT_Patrol / BB_Patrol - приоритетная ветка Move To Target прерывает патруль через Blackboard декоратор. 
Патруль выбирает случайную доступную точку в радиусе от Home, идёт к ней и ждёт секунду

Обнаружение по расстоянию 1200 см, потеря цели 1700 см. Чтобы оторваться, нужен спринт, после потери игрока ИИ снова патрулирует

NavMeshBoundsVolume покрывает площадку. 
Клавиша P в редакторе показывает навигацию и обходы препятствий

Ресурсы дерева, Blackboard и PCG в папке Content/AI
