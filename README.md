# дз1

## управление

W/A/S/D - движение
Пробел - прыжок
Left Shift - спринт
E - взаимодействие
1/2/3 - пасхалко

## Реализация

- C++-персонаж на основе Third Person Template.
- Спринт и взаимодействие через Enhanced Input.
- Делегат взаимодействия с выводом сообщения в Blueprint.
- Переключение анимации спринта по bIsSprinting.
- 1/2/3 нанейронено
